# PulseStock — Deniz Moda

Inventory × Ads decision dashboard. React + TypeScript + Vite + Tailwind static SPA.

- **Odoo data** (sales, stock, returns) is baked into `public/data/live.json` at build time.
- **Meta ads data** loads live in the browser from the serverless bridge on the
  ad-dashboard Vercel project: `https://ad-dashboard-git-main-deniz-cfb3.vercel.app/api/pulsestock`
  (falls back to `public/data/ads.json` snapshot if the bridge is unreachable).

## Deploy to Vercel (same flow as ad-dashboard)

1. Create a new GitHub repo, e.g. `pulsestock` (private is fine).
2. Push this folder:
   ```bash
   git init
   git add -A
   git commit -m "PulseStock initial deploy"
   git branch -M main
   git remote add origin git@github.com:<you>/pulsestock.git
   git push -u origin main
   ```
3. Vercel → **Add New → Project** → import the repo.
   - Framework Preset: **Vite** (auto-detected)
   - Build Command: `pnpm run build` (from vercel.json)
   - Output Directory: `dist`
   - No environment variables needed.
4. Deploy. You get `https://pulsestock-<you>.vercel.app` — works on mobile,
   auto-redeploys on every push to `main`.

## Refreshing Odoo data

`public/data/live.json` is generated by the sync script (runs outside the repo —
needs Odoo credentials in a `.env` that is **never committed**):

```bash
# .env format (kept locally, gitignored):
ODOO_URL=https://your-odoo-host
ODOO_DB=your_db
ODOO_USER=your_user
ODOO_API_KEY=your_api_key

python3 scripts/odoo_sync.py   # writes public/data/live.json
git add public/data/live.json && git commit -m "data refresh" && git push
# Vercel auto-redeploys with fresh numbers
```

### Automatic refresh (GitHub Actions)

`.github/workflows/odoo-sync.yml` runs the sync **every hour** and commits the
fresh `live.json`, which triggers a Vercel redeploy. One-time setup:

1. Repo → **Settings → Secrets and variables → Actions → New repository secret**
2. Add these four secrets (values = your `.env`): `ODOO_URL`, `ODOO_DB`,
   `ODOO_USER`, `ODOO_API_KEY`
3. Done. The **Actions** tab shows each hourly run; use **Run workflow** there
   for a manual refresh anytime.

The audit scripts (`scripts/audit_*.py`) are diagnostics for the sync logic;
they also read `.env` and are safe to keep in the repo (they contain no secrets).
